# 通海铁路专用线交互式卫星地图

## 打开方式

推荐在本目录运行：

```bash
./start_map.sh
```

浏览器会打开 `http://127.0.0.1:8088/`。如果该端口已被占用，脚本会自动寻找下一个可用端口并显示实际地址。也可以直接双击 `index.html`，本地卫星影像、缩放拖动和点位弹窗均可使用。

如需手动指定端口，例如 `9000`：

```bash
./start_map.sh 9000
```

## 使用方法

- 鼠标滚轮或右下角 `+ / −` 控件缩放地图。
- 按住鼠标拖动地图；地图范围被限制在包含铁路全线的正方形区域内。
- 点击任一红色点位，查看并复制该点的 CGCS2000 经纬度。
- 点击“显示全部点位”缩放至全部点位范围，点击“显示全线”恢复全线范围。
- 铁路使用淡蓝色线条显示。

## 瓦片缓存

通过 `start_map.sh` 启动时，页面会注册本地 Service Worker。点击右上角“缓存设置”可配置：

- 是否启用天地图在线瓦片缓存。
- 缓存保存天数，默认30天。
- 最大缓存瓦片数，默认2000张。
- 查看当前缓存数量或一键清除。

同一区域和缩放级别再次打开时会优先读取本地缓存。缓存键不包含天地图 Token；直接双击 `index.html` 时仍能使用本地影像，但浏览器不会启用 Service Worker 缓存。

## 在线天地图

页面自带一份裁切为铁路正方形范围的天地图卫星影像，可在没有 Token 时直接使用。若需要在线瓦片和更多原生缩放级别：

1. 在天地图控制台申请“浏览器端”Token。
2. 启动本地服务后，在页面左侧输入 Token 并点击“启用”。
3. 若瓦片不显示，请在 Token 域名白名单中加入 `127.0.0.1` 或实际部署域名。

也可以将 Token 填入 `config.js` 的 `tiandituToken` 字段。页面输入的 Token 只保存在当前浏览器的 `localStorage` 中。

## 刷新点位

地图当前读取项目根目录的 `CGCS2000经纬度.xlsx`，可在项目根目录执行：

```bash
python3 update_interactive_map_points.py
```

脚本会重新读取所有包含 `lat` 与 `lng` 列的工作表，并同步更新网页地图数据和 GeoJSON 文件。

## 数据说明

- 点位：来自 `CGCS2000经纬度.xlsx` 的全部有效坐标，CGCS2000（EPSG:4490）。
- 线路：OpenStreetMap 公开线位，并按工程验收资料核对名称、起讫和长度。
- 本地图用于浏览和位置核验，不替代正式测量放样。
